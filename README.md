# coin_dashboard

업비트 공개 시세 API로 원화(KRW) 마켓 코인 시세를 보여주는 Flutter 대시보드 앱입니다. 웹과 Windows에서 실행됩니다.

- 상태관리·DI: GetX
- 라우팅: go_router
- 구조: 클린 아키텍처 (data / domain / presentation), freezed 모델
